# Code of conduct

This project adopts the **Contributor Covenant, version 2.1**:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short: we pledge to make participation in this project a harassment-free
experience for everyone. Be respectful, welcome different viewpoints, accept
constructive criticism, and focus on what is best for the community. The full
text linked above defines expected and unacceptable behavior, the scope, and
the enforcement guidelines (correction, warning, temporary ban, permanent ban)
that the maintainers follow.

The Code of Conduct applies in all project spaces -- issues, pull requests,
discussions, and any other channel where someone represents the project.

## Reporting

Report unacceptable behavior to the maintainers privately:

- open a private report through GitHub Security Advisories at
  <https://github.com/YourAnonELF/traceon-replay/security/advisories/new> and
  start the title with "Code of conduct", or
- contact a maintainer directly through their GitHub profile.

Do not report conduct issues in public issues. All reports are reviewed
promptly and handled confidentially; the privacy and security of the reporter
are respected.
